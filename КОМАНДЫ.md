# Команды Капри

## Как позвать
- Скажи **«Капри»** — она появится и будет слушать 8 секунд. Можно сразу с командой: «Капри, открой ютуб».
- Клик по Капри или по иконке в трее. В меню трея ещё есть «Написать команду…», «Настройки…», «Проверить ПК», «Замолчать», «Спрятать».
- После ответа она ещё ~6 секунд слушает без имени — для уточнений.

## Микрофон
- Меню в трее → **«Настройки…»** → «Звук» → «Устройство» — выбор микрофона стрелками ◀ ▶. Переключается сразу и запоминается.
- «Капри, **какой микрофон**» — назовёт, через какой слушает.
- «Капри, **смени микрофон**» — переключится на следующий.
- Меню в трее → **«Настройки…»** → «Звук» — громкость микрофона именно для Капри, чувствительность
  (чтобы не реагировала на шум) и полоска уровня: видно, слышит ли она тебя.
  «Прослушивание» — сколько она слушает без имени после ответа (можно выключить совсем).
- Там же «Громкость» — громкость её голоса. Общая громкость Windows не меняется.

## Перебить
- Пока говорит: **«Капри…»** с новой командой, или **«стоп», «хватит», «молчи», «замолчи», «помолчи», «подожди», «перестань», «достаточно»**.
- Клик по Капри или «Замолчать» в трее.

## Сайты и поиск
| Сказать | Что будет |
|---|---|
| открой ютуб / вк / гугл / яндекс / почту / гитхаб / твич / карты / переводчик … | открывает сайт (список в `config.json` → `sites`) |
| открой сайт хабр точка ру | открывает любой сайт по адресу |
| найди рецепт борща / загугли … / поищи … | поиск Google |
| найди на ютубе лофи | страница поиска YouTube |
| найди фото котиков / покажи картинки с закатом / загугли обои киберпанк | Google Картинки |
| найди информацию о чёрных дырах / расскажи что-нибудь про … / загугли инфу о … | открывает Google и вслух пересказывает начало статьи из Википедии |
| открой ютуб **в хроме** / найди котиков **в яндекс браузере** / включи видео про космос **через эдж** | то же самое, но в названном браузере (хром, яндекс, опера, файрфокс/мозилла, эдж, брейв, вивальди) |

Обычно сайты открываются в браузере по умолчанию Windows. Чтобы Капри всегда открывала их в другом,
не меняя браузер по умолчанию, впиши его в `config.json`: `"browser": "хром"`.

## Музыка и видео (то, что сейчас играет)
Работает с YouTube в браузере, Spotify, Яндекс Музыкой, VK, Groove и другими плеерами, которые показываются
в плашке громкости Windows.

| Сказать | Что будет |
|---|---|
| пауза / поставь на паузу / останови музыку / выключи видео | пауза |
| продолжи / играй / сними с паузы / включи дальше | продолжить |
| следующий трек / дальше / пропусти | следующий трек или видео |
| предыдущий трек / прошлая песня | предыдущий |
| что играет / что за песня | назовёт трек |
| **поставь на 3:14** / поставь на три четырнадцать / включи с 2 минут | перемотка на точное время |
| перемотай на 30 секунд вперёд / промотай минуту | вперёд |
| перемотай назад на 10 секунд / отмотай на минуту | назад |
| включи сначала / начни сначала / включи заново | в начало |
| перемотай на тайминг 314 / поставь на 314 | на 3:14 |

Время можно говорить как угодно: «3:14», «три минуты четырнадцать секунд», «полминуты», «полторы минуты».
На YouTube в браузере перемотка на точное время перезагружает видео с нужного момента.

## Приложения
| Сказать | Что будет |
|---|---|
| открой / запусти телеграм, стим, дискорд, хром … | ищет среди установленных программ (понимает русские названия) |
| открой блокнот / калькулятор / проводник / диспетчер задач / параметры / панель управления / командную строку / терминал / пейнт | встроенные программы Windows |
| закрой дискорд / закрой телеграм | закрывает программу |
| сними задачу steam client helper / заверши процесс хром / кильни дискорд | завершает процесс (ищет и по имени, и по описанию, как в диспетчере задач) |
| … принудительно | если программа не закрывается сама |
| что грузит компьютер / какие процессы тормозят | назовёт процессы, которые больше всего едят процессор и память |
| закрой окно | закрывает активное окно (Alt+F4) |

Если подходят несколько программ (например, «открой cloud» → Cloudflare или Claude), Капри спросит,
какую открыть. Ответь номером («первое», «второе») или названием, «никакое» — отмена.

## Как Капри к тебе обращается
Меню в трее → **«Настройки…»** → «Профиль»: как тебя называть (своё имя, имя пользователя Windows, имя компьютера
или никак) и в каком роде говорить («скучал?» или «скучала?»). Это работает и в обычных фразах, и в разговоре
через нейросеть, сразу.

## Свои ответы
| Сказать | Что будет |
|---|---|
| когда я скажу «как дела», отвечай «лучше всех» | запомнит: на «как дела» будет отвечать «Лучше всех.» |
| на фразу «ты кто» отвечай «твой худший кошмар» | то же самое |
| забудь ответ на как дела | забудет |

Свои ответы проверяются раньше всех команд и нейросети. Фразу можно говорить чуть иначе — Капри всё равно узнает.
То же самое — в меню трея → «Настройки…» → «Мои сайты, программы и ответы» → вкладка «Ответы».

## Свои сайты и программы
| Сказать | Что будет |
|---|---|
| запомни этот сайт как музыка | запомнит адрес открытой вкладки браузера под этим названием |
| запомни эту программу как запрет | запомнит программу, окно которой сейчас на экране |
| сохрани программу под названием обход | то же самое |
| открой музыка / открой запрет | откроет запомненное |
| забудь сайт музыка / забудь программу запрет | забудет (и встроенные тоже, например «забудь сайт авито») |

То же самое — в меню трея → «Настройки…» → «Мои сайты, программы и ответы»: список, «Добавить…» и «Удалить».
Вручную — в `config.json` → `sites`, `apps` и `app_aliases`. Всё подхватывается сразу, без перезапуска.

## Печать текста и цепочки команд
| Сказать | Что будет |
|---|---|
| напиши привет как дела | печатает в активное окно и жмёт Enter (в чате — отправляет) |
| напечатай / введи список покупок | печатает без Enter |
| напиши … и отправь | печатает и жмёт Enter |
| нажми на поиск / перейди в поиск | курсор в поиск: YouTube — строка поиска, Telegram — поиск чатов, браузер — адресная строка |
| первый чат / второй чат / открой чат с мамой | открывает чат в Telegram (запустит его, если закрыт) |
| **открой телеграм, первый чат, напиши привет** | всё по очереди: откроет Telegram → первый чат → напишет и отправит |
| открой телеграм, чат мама, напиши я скоро буду | найдёт чат по имени и отправит сообщение |
| открой ютуб, найди котиков | поиск прямо на YouTube |
| открой ютуб, нажми на поиск, напиши лофи | то же самое по шагам |
| открой блокнот и напечатай … | откроет Блокнот и напечатает текст |

- Всё, что после «напиши», считается текстом сообщения.
- «Напиши стих / рассказ / анекдот» — это просьба к нейросети, а не печать.
- Перед печатью Капри проверяет, что активно нужное окно. Если переключиться не удалось, она ничего не печатает.
- Не нужен Enter по умолчанию — поставь в `config.json` `"type_press_enter": false`.

## Прокрутка страниц
Листает активное окно: браузер, документ, проводник, чат.

| Сказать | Что будет |
|---|---|
| прокрути вниз / пролистай вверх / листай ниже | на один экран |
| прокрути немного вниз / ниже / выше | чуть-чуть |
| прокрути вниз на 3 экрана | на несколько экранов |
| в самый низ / прокрути в конец | до конца страницы |
| в самый верх / прокрути в начало страницы | в начало |
| листай медленно / листай сама (быстро) | плавно листает сама, пока не скажешь **«стоп»** или «хватит» (можно без имени) |

Курсор мыши на мгновение уходит в центр окна и возвращается на место.

## Клавиши
**«Нажми …»** — нажимает клавиши или сочетание в активном окне.

- Примеры: нажми вин таб · нажми контрол шифт эскейп · нажми альт эф четыре · нажми контрол цэ · нажми энтер · нажми пробел три раза · нажми стрелку вверх
- Понимает: вин/виндоус/windows, контрол, шифт, альт, таб, энтер, эскейп, пробел, бэкспейс, делит, инсерт, хоум, энд, пейдж ап/даун, стрелки (вверх/вниз/влево/вправо), принт скрин, капс лок, F1–F12 («эф пять»), буквы (латиницей или «си», «дэ», «пэ», «эс»…), цифры
- «… N раз» — повторить

## Разговор
Всё, что не похоже на команду, — разговор с Капри (локальная нейросеть, без интернета): вопросы, советы, анекдоты, «как дела».
Пока она отвечает на вопрос, она скачет по экрану красной молнией.
На свежие темы (погода, новости, курсы, цены, матчи) она открывает поиск в Google.
Если не нужно, чтобы она сама открывала поиск, выключи в меню трея → «Настройки…» → **«Искать в браузере, если не знаю»**
(или поставь в `config.json` `"search_when_unsure": false`) — тогда она просто скажет, что не знает.
Команды «найди …» и «загугли …» при этом работают как обычно.

## Сама по себе
Раз в 15–40 минут затишья Капри может появиться и что-нибудь сказать, иногда — прогуливаясь по экрану.
Во время игр и видео на весь экран не появляется.
Выключить — меню трея → «Настройки…» → **«Появляться самой»** → ВЫКЛ (сразу, без перезапуска).

## Настройки
Всё настраивается в `config.json`: голос и эффекты (`voice_*`), частота появлений (`chatter_*`, `roam_chance`),
прыжки молнией (`teleport_on_answer`), перебивание голосом (`barge_in`), свои сайты и программы.
